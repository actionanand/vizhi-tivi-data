# Research-only leads (not published)

`channel-candidates.json` contains factual, source-cited television channel candidates
that need editorial and legal review. This file is deliberately **not** copied to
GitHub Pages or included in public catalogue releases. No candidate has a playable URL.

A broadcaster's public website, a free-to-watch page, or a public M3U playlist is
**not** by itself a redistribution license or permission to embed a direct stream.
Check stream usage terms and obtain permission where necessary before placing an
entry in `data/streams.json`. Record the permission evidence URL and reviewer notes.

Confirmed channels belong in `data/channels.json` with stable IDs/numbers.
Only streams that satisfy the rights and verification gates will be published.
